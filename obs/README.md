# OBSに翻訳字幕を表示する

翻訳の設定・開始・停止と音声再生はChrome拡張で行います。
OBS用ページは字幕だけを表示し、背景・帯・操作ボタン・音声はありません。
この構成ではChromeとOBSを同じPCで動かしてください。

## 使い方

1. Node.js 22以降を用意し、プロジェクトのルートで `npm run obs` を実行します。
   追加パッケージのインストールは不要です。利用中はこのコマンドを起動したままにします。
2. `chrome://extensions` で開発用拡張を読み込み直します。
3. 拡張の設定画面で **OBS字幕出力 → 翻訳字幕をOBSへ送信する** をオンにして、
   ローカルホストへのアクセスを許可します。ブラウザがローカルネットワークへの許可を
   追加で求める場合も、この用途に対して許可してください。
4. OBSで **ソース → ＋ → ブラウザ** を追加し、ローカルファイルはオフにして
   URLに `http://127.0.0.1:8765/` を指定します。
   幅1920・高さ1080など、配信キャンバスと同じサイズにします。
5. Chrome側で通常どおり翻訳を開始します。字幕はリアルタイムで更新されます。

「ページ上の字幕」のスイッチとは独立しています。ページ上の字幕がオフでも
OBS出力は利用できます。初期設定ではタブ音声の翻訳字幕のみを表示します。
翻訳停止・OBS出力オフで字幕を消します。中継への通信が途切れた場合にも、
最後の字幕は指定した表示時間を過ぎると消えます。

## 表示の変更

URLのパラメーターで調整できます。

| パラメーター | 値 | 初期値 |
|---|---|---|
| `direction` | `tab`（タブ）、`mic`（マイク）、`both`（両方） | `tab` |
| `size` | 文字サイズ、12〜160px | `48` |
| `hold` | 最後の更新から字幕を消すまでの秒数、1〜60秒 | `8` |

マイクの翻訳だけを大きく表示する例:

```text
http://127.0.0.1:8765/?direction=mic&size=64&hold=10
```

文字は白・黒縁取り、下中央、最大3行です。両方を選んだ場合は各方向で最大3行です。
通常のブラウザでは透過領域が白く見えることがありますが、OBSでは下の映像が見えます。
位置・色・フォントなどはOBSのブラウザソースのカスタムCSSで調整できます。
長い字幕は3行で切り詰めます。表示領域に合わせて文字サイズを調整してください。

## データの扱い

中継は `127.0.0.1:8765` だけで待ち受け、翻訳文と方向のみを受け取ります。
音声・APIキー・原文は送りません。字幕は各方向の最新1件をメモリ上に保持し、
ファイルに保存しません。別PCへの送信や公開サーバーへの設置には対応していません。
同じPCのアプリはこの字幕URLへアクセスできます。

表示されないときは中継が起動しているか、設定の送信スイッチと権限が有効か、
OBSの `direction` が翻訳中の方向に合っているかを確認してください。
ポート8765が使用中の場合は、そのポートのアプリを終了してから再起動します。
中継の停止はターミナルで Ctrl+C です。
